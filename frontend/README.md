# Vitalis frontend (in progress)

React rewrite of the Vitalis UI, built in parallel with the existing Jinja2 app — see
`../PROGRESS.md` for the full roadmap and `../README.md` for how to run both together.

```bash
npm install
npm run dev      # dev server with backend proxy, see vite.config.js
npm test         # Vitest + React Testing Library
npm run build    # production build
```
